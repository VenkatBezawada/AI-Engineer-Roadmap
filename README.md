# AI Engineer · 240-Day Path

> A self-paced, day-by-day roadmap from non-technical to junior AI engineer — built for late-night learners studying 90 minutes a day.

**🌐 Live: [venkatbezawada.github.io/AI-Engineer-Roadmap](https://venkatbezawada.github.io/AI-Engineer-Roadmap/)**

## Why this exists

Most AI roadmaps are either too vague ("learn Python, then ML, then LLMs") or scattered across 50 different videos. This one is a single page with **240 specific days**, each with:

- A 90-minute time block designed for 10pm–7am study
- Plain-English concept explainers with analogies (no math anxiety)
- Concrete action steps as a checklist
- Curated external links — only for video lectures and hands-on labs

Built for India's job market, April 2026.

## Features

- 🎯 **Focus mode** — distraction-free single-day view with a built-in 90-minute timer
- ✅ **Step-by-step tracking** — tick off action items, progress saves automatically
- 🔥 **Streak counter** — keeps you accountable for the long haul
- 💾 **Export/Import progress** — full backup & restore as JSON
- 🔍 **Search & filter** — find days by topic ("RAG", "Docker", "Pandas")
- 📱 **Mobile-friendly** — usable on phone for late-night reading
- 🔒 **Privacy-first** — no analytics, no backend; progress stays in your browser

## Curriculum overview

| Month | Focus |
|-------|-------|
| 1 | Foundations — Python, Git, basics |
| 2 | Math + Classical ML |
| 3 | Generative AI — LLMs, prompting, APIs |
| 4 | Agents, advanced RAG, evaluation |
| 5 | Production AI — Cloud, Docker, MLOps |
| 6 | Specialization (healthcare / fintech / legal / edtech / ecommerce) |
| 7 | Portfolio, resume, interview prep |
| 8 | Job hunt — apply, interview, land it |

## Tech

Single self-contained HTML file. No build step. No backend. Pure HTML + CSS + vanilla JavaScript with `localStorage` for persistence.
